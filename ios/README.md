# iOS build

The iPhone build's documentation now lives in the [repository README](../README.md) —
this fork exists for that build, so it belongs on the front page rather than in
a subdirectory.

This directory still holds the build itself: `CMakeLists.txt`, the SwiftUI key
strip (`NativeControls.swift`), the folder picker and platform glue
(`sim_ios_platform.m`, `SwiftControlsBridge.mm`), `Info.plist.in` and the launch
screen.
